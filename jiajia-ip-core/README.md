## 🚀 GitHub 上传与 GitHub Pages 部署指南

### 1. 初始化并提交至 GitHub 仓库
在当前 `jiajia-ip-core` 目录下打开终端，执行以下命令：
```bash
git init
git add .
git commit -m "feat: init jiajia-ip-core standalone web package"
git branch -M main
git remote add origin https://github.com/<你的GitHub用户名>/<你的仓库名>.git
git push -u origin main
```

### 2. 启用 GitHub Pages 免费在线访问
1. 进入 GitHub 仓库页面，点击 **Settings**（设置）；
2. 在左侧菜单中找到 **Pages**；
3. 在 **Build and deployment** 下的 **Branch**，选择 `main` 分支，路径选择 `/ (root)`，点击 **Save**；
4. 等待 1–2 分钟，即可获得全球可访问的在线网页链接：
   `https://<你的GitHub用户名>.github.io/<你的仓库名>/`
